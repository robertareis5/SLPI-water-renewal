# SLPI-water-renewal

Datasets and numerical model files used in SisBaHiA® computational simulations for hydrodynamic circulation, Eulerian water renewal rates, and water age analyses in the Piratininga-Itaipu Lagoon System (SLPI), Niterói, Rio de Janeiro, Brazil.

---

## Data

This repository contains datasets used in the SisBaHiA® simulations for the Piratininga-Itaipu Lagoon System (SLPI).
